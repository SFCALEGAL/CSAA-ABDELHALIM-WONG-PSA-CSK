This is also not confined to the courthouse. A complaint to the California

If Department examiners find an empty or near-empty investigation file, the
first consequence is that CSAA has already failed a basic claims-handling
duty. Insurance Code section 790.03(h)(3) and title 10, California Code of
Regulations, section 2695.7(d) require a prompt, thorough investigation;
section 2695.3 requires the file to document it. A file with no 911
request, no body-camera request, no dispatch pull, no statement from the
claimant, and no recorded statement from the insured is evidence that the
company did not investigate, did not record what it did, or both. That is a
violation on its own terms, before anyone reaches intent.

The Department can treat that file as an unfair claims practice.
Consequences start administrative: a written finding, a demand that the
company account for the missing work, a cease-and-desist order under
section 790.05, and civil penalties under section 790.035 of up to $5,000
per act, or $10,000 per act if the Department finds the conduct willful.
The company can be ordered to correct procedures, retrain adjusters, and
keep complete files. In a market-conduct examination, one empty file is
counted with the others, and if the pattern is systemic the penalties scale
and the findings become public.

that CSAA never investigated liability, the collision, or the insured's 911
